# 巡洋战略舰 · 工程存档 v0.10.8

抖音本地生活直播中控助手。Windows / macOS 单机运行，配置与数据只留在本机。

本篇是工程的归档说明，**源码包在页面底部的附件里**，换设备时下载附件解压即可继续开发或打包。

## 版本信息

- 版本号：v0.10.8（见 package.json）
- 归档日期：2026-10-24
- 归档形态：源码工程（不含安装包，安装包请在本机自行打包）
- 运行环境：Electron 44 + Node

## 怎么跑起来

1. 解压源码包，进入目录
2. `npm install --no-audit --no-fund`（国内建议配镜像，Electron 二进制容易卡住）
3. `npm start`

若 Electron 二进制没下来，单独补一次：`node node_modules/electron/install.js`

## 怎么打包

- Windows：`npm run dist:win`，产物在 `dist-win*/巡洋战略舰 Setup <版本>.exe`，安装器支持自选目录，默认 `D:\Program Files\巡洋战略舰`
- macOS：必须在 macOS 上执行 `bash scripts/build-mac.sh`（跨平台打不出 dmg）

## 工程结构

- `main.js` / `preload.js`：主进程与安全桥接，含内存面板、窗口与 IPC
- `src/index.html` / `src/styles.css` / `src/app.js`：界面骨架、样式、渲染层与调度引擎
- `src/app.js` 内的 PageBus 负责页面独占与排队，Worker 负责隐藏的后台工作页
- `scripts/`：出厂配置校验（make-default-config.js）、打包源码（pack-src.py）、Mac 出包（build-mac.sh）
- `build/`：图标与 NSIS 安装器脚本（installer.nsh，含自选安装目录逻辑）
- `test/`：界面、注入、后台页、协议拦截、并发压测五套自测脚本

## 功能模块

- 弹讲解：循环弹团购卡、常驻单卡，走接口通道不占画面
- 自动发评：评论组轮发、随机间隔、可自动置顶
- 发优惠券：扫描后台券列表，按库存档位定时发放
- 秒杀投放：定时开启 / 停止，剩余不足自动补库存
- 实时数据：只读看板，在线 / 观看 / 涨粉 / 成交一把看

## 这一版相对 v0.2.2 的主要变化

- 自动化改走页面同源的接口通道，不再靠点画面，多模块可以真正并行
- 新增隐藏的后台工作页，自动化不占用你看得见的中控台，主界面完全不动
- 调度加了单页面锁、优先级队列与真人操作让位，冲突场景不再互相打断
- 稳定性：后台页失败不再误判故障、抽屉遮罩卡死可自愈、内存占用可查看与回收
- 打包：NSIS 支持自选安装目录，默认装到 D 盘；Mac 端回归 build-mac.sh 出包
