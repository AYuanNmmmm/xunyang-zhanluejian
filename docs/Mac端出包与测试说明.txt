巡洋战略舰 v0.10.8 —— Mac 端出包与测试说明
================================================

零、先说结论
------------------------------------------------
Mac 的安装包（.dmg / .app）**必须在 Mac 上打包**。
electron-builder 26 起拒绝跨平台构建 macOS：

    ⨯ Build for macOS is supported only on macOS

所以在 Windows 这台机器上，出不了 Mac 安装包——这是工具限制，不是配置问题。
工程里早就准备好了脚本：**scripts/build-mac.sh**，在 Mac 上跑一下即可。

Windows 安装包已经打好了：
    dist-win4\巡洋战略舰 Setup 0.10.8.exe（108 MB，安装向导可自选位置，默认 D:\Program Files\巡洋战略舰）


一、Mac 出包（推荐，出正式 .dmg + .zip）
------------------------------------------------
在 Mac 上，终端进入工程目录执行：

    bash scripts/build-mac.sh

只想要 M 系列芯片的包（快一半时间）：

    bash scripts/build-mac.sh --arm64-only

脚本会做这些事（已内置，不用手动干预）：
  1. 找 node（含 Homebrew / nvm / WorkBuddy 托管运行时）
  2. 走国内镜像（electron + electron-builder-binaries 走 npmmirror），避免下载卡死
  3. **先跑 `npm run predist:mac`：重新生成出厂配置并校验**
     —— 新机不能带任何商品/券/秒杀卡，有残留会直接中止打包
  4. `CSC_IDENTITY_AUTO_DISCOVERY=false`：自用工具不做 Apple 公证签名
  5. electron-builder --mac：产出 arm64 + x64 两套

产物在 release/ 下：

    巡洋战略舰-0.10.8-arm64.dmg / .zip      M 系列芯片
    巡洋战略舰-0.10.8.dmg / .zip            Intel 芯片

首次跑要下载两套 Electron 运行时（各约 130 MB），几分钟，之后就快了。


二、不出包也能测（源码绿色版）
------------------------------------------------
如果测试员的 Mac 上装了 Node 22+，可以不出包，直接给源码：

    release\巡洋战略舰-源码-0.10.8.zip（1.9 MB，干净版）

Mac 上解压，双击 **「首次安装.command」**，脚本会自动：
  查 Node → npm install（走 npmmirror 镜像，约 200-400 MB）→ 补 Electron 二进制 → 清隔离标记 → 启动
之后每次双击 **「start.command」** 即可。

注意：这个 zip 是**干净版**，里面只有 data/config.default.json，
不含任何商品 / 券 / 秒杀卡 —— 装好要自己抓（见第四节）。


三、测试员怎么装
------------------------------------------------
  M 系列芯片（M1/M2/M3/M4）→ arm64 包
  Intel 芯片              → x64 包
  不确定：苹果菜单 →「关于本机」→ 看「处理器 / 芯片」一行

  1. 打开 dmg，把「巡洋战略舰」拖进「应用程序」
  2. 打开：在「应用程序」里**右键**点它 →「打开」→ 弹窗里再点「打开」
  3. 若提示「已损坏，无法打开」/「无法验证开发者」，终端执行：

         xattr -cr /Applications/巡洋战略舰.app

     再双击即可。（本包未做 Apple 签名，macOS 的常规处理，不是包坏了。）

  打包版的配置文件在：
        ~/Library/Application Support/巡洋战略舰/config.json
  首次启动会自动从安装包里的出厂配置迁移。


四、第一次打开是空白的，这是正常的
------------------------------------------------
出厂包**不带任何商品 / 券 / 秒杀数据**——那些是你自己直播间的，必须自行抓取。

  ① 打开 app → 等后台中控台加载
  ② 扫码登录抖音账号
  ③ 进入直播中控台，确认已开播
  ④ 左侧「商品」页 → 点「⚡ 同步全部」→ 约 10 秒，商品 / 券 / 秒杀入口一次抓齐
  ⑤ 勾选要讲解的商品 → 其它功能就能用了


五、本版（v0.10.8）重点
------------------------------------------------
  · 【修复】开播后一直提示「官方抽屉/弹窗正开着」、所有功能卡死 —— 已修
    现在最多让位 15 秒就放行；连续误判 3 次会自动关掉这项礼让（日志有写）
  · 【新增】接口通道：弹讲解走抖音官方接口，不再点画面，可与发评/发券并行
  · 【新增】「实时数据」页（⑤）：在线人数、观看、涨粉、成交、GMV，含单品表
  · 【整理】「商品」页唯一总入口「⚡ 同步全部」，零散按钮降级为「↻ 只…」
  · 【新增】设置 → 内存：按进程查看占用，两个回收按钮
  · 【新增】设置 → 数据 →「清空业务数据」：换机/交机前一键清干净


六、遇到问题怎么反馈
------------------------------------------------
  · 日志区截图（左侧底部，可切换「全部 / 任务 / 错误」）
  · Mac 机型 + 芯片 + macOS 版本
  · 具体现象：卡在哪一步、有没有报错文字
