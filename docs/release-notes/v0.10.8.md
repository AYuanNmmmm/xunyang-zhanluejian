# v0.10.8 · 首个开源版本

抖音本地生活团购直播间中控助手，Windows / macOS 单机运行。

## 安装

- **macOS（Apple 芯片）**：下载 `xunyang-zhanluejian-macOS-arm64-v0.10.8.zip`，解压后把 `巡洋战略舰.app` 拖进「应用程序」。首次打开右键 →「打开」；提示「已损坏 / 无法验证开发者」时执行 `xattr -cr /Applications/巡洋战略舰.app`。
- **源码**：`npm install && npm start`。Windows 可直接双击 `首次安装.bat` / `start.bat`。

出厂包不含任何商品、优惠券、秒杀数据。首次使用：登录抖音 → 进直播中控台 → 「① 商品」→「⚡ 同步全部」。

## 本版重点

- 修「一直提示『官方抽屉/弹窗正开着』、所有功能都动不了」：`officialBusy()` 增加视口判定与命中测试，`PageBus` 增加 15 秒超时放行与连续误判自愈。
- 修「用着用着弹出『需要使用新应用以打开此 bitbrowser 链接』」：`guardSchemes()` 在 webview 上拦截 `will-navigate` / `will-frame-navigate` / `will-redirect`，非 http(s) 类协议一律拦下并记日志。
- 修「macOS 启动后 20~110 秒必闪退」：后台页健康探针从业务元素改为 `body`（下播后元素本就不存在，会被误判成卡死并触发 reload → macOS 27 上连锁崩溃）；主进程加 `use-system-dns` 规避 c-ares 解析抖音多层 CNAME 的段错误；Electron 固定到 37.10.3。
- 打包配置路径判定改为同时认 `.app/Contents` 与 `app.asar`，手动打包与 asar 打包都不会把配置写进包内。
- 新增「实时数据」页：在线人数、观看、涨粉、成交、GMV 与单品明细。
- 弹讲解走官方接口通道，不再点画面，可与发评/发券并行。
- 「商品」页收敛为唯一总入口「⚡ 同步全部」，零散按钮降级为 `↻ 只…`。
- 设置页新增按进程内存面板与两个回收动作；「清空业务数据」用于换机前清理。

## 验证

- 回归自测 91 项全过：`ui-test` 41 / `auto-test` 42 / `scheme-guard` 8。
- macOS 包：启动后正常进入抖音登录页，外部协议唤端被拦截，配置正确落在 `~/Library/Application Support/巡洋战略舰/config.json`。

## 已知限制

- macOS 包仅 arm64（Apple 芯片），Intel 机器请用源码版或自行出包。
- 未做 Apple 签名与公证。
- 强依赖抖音后台 DOM，改版后需在「高级」页重新分析结构并校准选择器。
